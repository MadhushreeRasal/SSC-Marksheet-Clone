# SSC Marksheet Clone

A frontend practice project recreating an SSC marksheet layout using **HTML and CSS tables**.
This project focuses on structured table design, document-style layouts, typography, and webpage formatting concepts.

**Live Demo:**
[https://madhushreerasal.github.io/SSC-Marksheet-Clone/](https://madhushreerasal.github.io/SSC-Marksheet-Clone/)

## Features

* Detailed marksheet table structure
* Document-style webpage layout
* Styled typography and formatting
* Board examination inspired design
* Use of `rowspan` and `colspan`
* Images, seal, and signature placement
* Built using pure HTML and CSS

## Technologies Used

* HTML5
* CSS3
* Google Fonts

## Concepts Practiced

This project helped practice and improve understanding of:

* HTML tables (`table`, `tr`, `td`, `th`)
* `rowspan` and `colspan`
* Structured document layouts
* CSS styling and formatting
* Typography and font integration
* Image positioning and alignment
* Webpage organization

## Note

This is a frontend practice project created for educational and learning purposes only.
The layout is inspired by SSC marksheet formatting and was recreated to practice HTML table structures and CSS styling techniques.
